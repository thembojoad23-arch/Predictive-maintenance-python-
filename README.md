# Predictive Maintenance System

Built for Kyagalanyi Coffee Ltd to monitor electric motor health.

What it does:
- Processes historical failure data with Python
- Sets automated alerts based on running hours
- Uses anomaly detection to forecast failures before they happen

Goal: Reduce downtime by catching failures early.
